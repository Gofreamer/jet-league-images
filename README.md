# Jet League Images

Repositório simples para hospedar imagens da Jet League no GitHub Pages e usar URLs diretas no TransferJet/Fantasy/Jet Cards.

## Estrutura

- `images/agents/` — imagens principais dos agentes
- `images/cards/` — artes específicas de cartinhas
- `images/special/` — edições especiais, campeões, MVP etc.
- `images/teams/` — escudos/logos dos times

## Como pegar a URL

Depois de ativar o GitHub Pages, a URL de uma imagem seguirá este formato:

`https://SEU-USUARIO.github.io/jet-league-images/images/agents/nome-do-agente.png`

Exemplo:

`https://SEU-USUARIO.github.io/jet-league-images/images/agents/shikao.png`

## Dicas

- Use nomes simples, minúsculos e sem espaços.
- Prefira `.webp`, `.jpg` ou `.png`.
- Evite substituir uma imagem importante mantendo o mesmo nome se o navegador estiver usando cache; quando necessário, use um nome novo como `shikao-v2.webp`.
- Para artes de cartas especiais, use nomes como `shikao-champion-c3.webp`.
